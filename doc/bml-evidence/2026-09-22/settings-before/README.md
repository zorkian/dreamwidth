# Legacy settings baseline

Captured in the isolated foreman development container on 2026-09-22 before
settings hub conversion, using seeded local accounts. These 15 states cover
anonymous, personal and community categories, denied authas and narrow display.
The paired results file records HTTP, JavaScript and resource observations.

These are rendering baselines, not mutation acceptance. Other Sites reproduces
the existing XPostAccounts display exception. The separate disposable settings
browser test characterizes actual saves and missing legacy unsaved-change guard.
