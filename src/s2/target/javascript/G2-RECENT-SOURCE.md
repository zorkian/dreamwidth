# General Recent source model

Recent preparation now consumes the complete source-counted window separately from
public Entry descriptors. A sticky-skipped or suspended row contributes to navigation
count without gaining a text/author projection. Visible sticky entries precede the
ordinary window; original stored sticky IDs retain their skip semantics even when
Entry loading replaces the low byte. Header facts come from the existing witnessed
visibility read and remain bound to final revalidation; no new queries are introduced.

The factory preserves native day flags, feed links, head contributions, navigation and
max-scroll fallback. RecentPage assigns its lastentry variable to the current entry
before setting end_day on a date change; this source behavior is deliberately retained.
Public source helpers provide images, localization/resource contributions and display
notification effects. They are required installed operations, not empty product defaults.

Query escaping uses native byte/flag and codepoint sprintf semantics. make_link retains
last-wins hash values; native hash iteration does not promise a query parameter order.
Tests compare logical query fields when multiple keys are present rather than invent a
seeded native order.

Compact independent proof executes retained RecentPage with declared synthetic public
providers, then exercises a source-compiled program using one initialized Context. Initialization changes
item count to three and persists its mutations. Guarded SQL tests cover sticky/window
projection, private/suspended no-read, mismatched stored anum and final freshness.
This is model/session proof, not an ordinary installed-worker or HTTP milestone.
Installed body/subject cleaners, public helper/resource/hook binding, Entry comments/OG,
request context and final page postprocessing remain mandatory ongoing work. The subject component was not consumed at this checkpoint or replaced with an identity cleaner.

Standard images use an explicit request Context during initialization. Native assigns
CURR_CTX only after s2_context initialization (LJ/S2.pm139), so initialization-time
get_image can observe a prior request or fail. Current-Context isolation is a
deterministic protective difference, not cross-request global parity. At the actual
s2_run boundary (line328), the render lookup cache resets; Image references already
attached to prepared models remain aliases, and the next lookup rebuilds from the
then-current properties. No cache or Context is shared between requests.
