# General standard-image integration

Trusted setup exports installed image descriptors as native scalar frames, including
original numeric kinds, PV caches, byte flags and undefined fields. The private file
and existing no-connect/output-suppression boundary remain unchanged. No descriptor
or translation key can be selected by an author-controlled IPC argument.

The credential-free worker uses the reviewed Image callbacks and one request Context.
Prepared Image references remain aliases. The trusted render-boundary operation resets
only the lookup cache immediately before output begins, reproducing s2_run's reset;
the next get_image uses then-current properties. Native assigns CURR_CTX after context
initialization, so initialization-time lookup can see an earlier request or fail.
Explicit current-Context isolation is a protective difference, not global-lifetime parity.

Installed translation binding performs the sixteen ordered descriptor lookups through
the parent public session. It preserves missing versus empty keys and native byte/flag
and lowercase semantics, using the installed scalar profile for flagged keys. Public
language MyISAM reads use the already-reviewed SELECT-only exception; private identity,
style and content tables retain their transactional requirements. Reached translation
rows and files are reread before the final selected-authority check. Cache and native
fallback persistence remain intentionally absent under the existing private-viewer scope.

Only positively branded native helper errors cross the private protocol as program
errors. Unknown infrastructure errors remain terminal. The manifest admits one exact
additional pure navigation module required by the reached Image set_url helper; no
directory, dependency, syscall or permission grant expands.

Focused evidence includes installed no-connect export/private-file controls, actual
SELECT-only MyISAM descriptor witnesses and mutations, native ML debug undefined/flag
controls, closed-runtime manifest negatives, and source-corresponding plus missing-source
recovered programs with initialization/prepared/render Image aliases. The worker test
uses the explicitly declared model test entry with the owning exported facts and actual
SQL/file translation provider. The native Image oracle declares synthetic, unused ML
labels; native translation precedence is proved independently. This is not the
ordinary installed worker, binary resource-route parity or general HTTP completion.

Request language initially uses DEFAULT_LANG or LANGS[0]; the post-context merge uses
DEFAULT_LANG while preserving defined scope, including empty scope. Compact native
controls prove both phases. Known missing-language errors retain their public absence
witness for final reread; unknown failures remain terminal.

Remaining public helper eval effects and complete diagnostic wording,
body/property/subject cleaning, comment preparation,
installed worker/factory and final page postprocessing remain mandatory consumer work.
The held subject component is not consumed or replaced with an identity cleaner.
