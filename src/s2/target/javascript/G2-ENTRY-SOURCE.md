# General selected Entry preparation

The selected Entry factory follows retained Entry_from_entryobj ordering: subject/event,
external and internal embedded expansion, adult transformation, journal/poster aliases,
picture selection, mood theme, tags, comment metadata and the native Entry constructor.
Its required operations are installed public helpers, not identity-cleaner defaults.
Only named approved formatting fields cross the selected-text boundary; original SQL
witnesses and the existing final reread remain separate.

The setup exporter obtains memories, tellafriend and esn from installed LJ::is_enabled
with no arguments, under the sticky no-connect guard. Loaded source/config identities
bind the snapshot. These setup facts do not establish equivalence for request-dependent
site callbacks; that context still requires consumer integration.

Focused proof uses actual retained native Entry construction with declared synthetic
public providers, guarded SQL formatting rows, and a compiled EntryPage printing the
prepared fields. Source-corresponding and missing-source recovered programs retain one
initialized Context through GB output and match native bytes. This is model/session
proof, not acceptance of the ordinary installed worker or HTTP route. Actual subject,
clean_event, public-helper, request-context and final page postprocessing integration
remain mandatory. The held subject component is not consumed.
