# General compiler foundation

This foundation compiles a source-backed active layer stack only when freshly
generated native code matches the stored active bytes exactly. Missing source
or mismatched active code remains an unresolved recovery dependency. It does
not yet replace the serving pipeline.

## Active version and compilation

`ActiveStyleSnapshot` carries the ordered layer IDs, owners, parents, types,
authoritative system user ID, compile times, source candidate bytes and exactly
decoded/decompressed active compdata bytes. It accepts arbitrary identities;
there is no source catalog or property-name allowlist. The loader must supply
these facts from its bracketed snapshot. Serving integration remains G2 work.

`ArtifactCompiler` independently clones a freshly reconstructed parent checker
for native and JS compilation. Native output must match the active bytes
exactly before JS is accepted. A newer saved source with older active code
returns `recovery`; missing source does too. It never executes the newer source
as a substitute. A saved source candidate that cannot compile also returns that
recovery dependency while the persisted program remains authoritative. Stored
native code and DB checker blobs are not executed or
thawed. The disjoint generated-Perl recovery frontend will supply the other
active-version path after its own review.

The owner inequality against `systemUserId` sets untrusted compilation for every
layer type, including layouts and themes. Native and JS use the same mode.
Safe-print and notags instructions remain distinct. G2 must provide the native
streaming HTMLCleaner; the existing finite safe-chunk filter is not the general
replacement sink.

## Artifacts, isolation and bounds

`ArtifactCache` uses a caller-specified absolute local root owned by the process
with mode 0700. It creates a 0600 producer key and publishes 0600 artifacts by
rename from its own temporary directory. Concurrent identical requests share
one compilation. HMAC authentication, compiler identity, schema, ABI, dependency
key and emitted-code digests are checked before reuse. Corruption refuses; it
does not silently bless edited code by rebuilding. Plain caller-created program
objects cannot be instantiated. These APIs belong to the trusted local producer;
the renderer must not receive the cache key or access to the producer root.

The key includes ordered layer identities, trust mode, source and active-byte
hashes, parents, compile times, system identity and style identity. Compiler
module bytes, driver, Perl executable, isolation executable and runtime source
enter the compiler digest. Replacing a dependency requires a new compiler
instance and changes the key. Legacy compiler emission remains temporarily
unchanged for the old reviewed serving artifacts; this general path explicitly
enables `generalHashes`, whose implementation enters that digest.

The separate Linux x86-64 compiler launcher requires Landlock ABI 3 and seccomp.
It reads only the designated compiler files and required system Perl/library
directories. Filesystem writes, sockets, child creation, process inspection and
inherited descriptors are denied; no site configuration or DB credentials are
passed. Unsupported kernels fail closed. Administrative executable/module paths
must identify the installed trusted toolchain. Compiler input is data on stdin.

Each source/active field is bounded by MEDIUMBLOB capacity, 16,777,215 bytes;
the job aggregate is 64 MiB. The compiler has a separate 1 GiB address-space
budget, 60-second CPU/wall deadline, 64 MiB output limit and two concurrent jobs
per compiler instance. These are workload safety bounds, not account or language
limits. Busy/failure remains retryable compiler unavailability, not permanent
product admission. No generated artifact is stored in Git or the database.

## Runtime and recovery ABI

Layer metadata retains typed declarations, attributes, property uses/groups and
values. Context construction merges the ordered stack, copies mutable composite
data and performs native per-declaring-layer enum pruning. Only truthy merged
values are checked. Alternating keys and labels retain duplicate-last-wins and
false-label semantics; invalid values are deleted, not replaced by defaults.
General hashes use null-prototype records, including empty/default allocation;
legal `__proto__` and `constructor` keys remain data. Expressions are evaluated
once in source order.

The recovery ABI exposes `Layer.registerClassMetadata`,
`Layer.registerGlobalFunction`, `runtime.makeHash` and
`runtime.recoveryCheckpoint`. Checkpoints use the native default four-second
deadline and repeated-frame threshold 50, with function/print cadences 16/8.
The JS recursion counter uses symbolic frames rather than native Perl source
locations. Recovery emits loop checkpoints; complete source-loop instrumentation
and independent worker fail-stop enforcement remain part of general serving
integration. This foundation is not a complete execution sandbox or host port.

General JS super calls pass the exact class selected by the checker. This is the
native `get_object_func_num` lookup class, not a runtime alias frame or a class
whose parent should be selected again. An inherited alias on a grandchild is
covered by the independent native fixture. Recovery can use the same exact
lookup or its validated exact `getFunction` dispatch.

Hash iteration order is not a seeded native equivalence guarantee. The compact
fixture uses a single remaining hash key where it asserts output order. Generated
code is instantiated only inside a credential-free renderer, never the DB parent.

## Reproduction

Run in the owning devcontainer with its existing locked dependencies and Node24:

```sh
cd "$LJHOME/src/s2/target/javascript"
export PATH=/opt/dw-node24/bin:$PATH
npm run check
npm run check:page
node --test dist/tools/compile-active.test.js
cd "$LJHOME/src/s2"
PERL5LIB="$LJHOME/src/s2:$PERL5LIB" perl runtests.pl --force
```

The focused test compiles the launcher into an isolated temporary directory and
removes only that directory afterward. Its native oracle executes compiler output
from fixed trusted synthetic fixtures, not database programs. It checks real
custom dispatch/inheritance/composites, safe printing, false enum labels,
source/active mismatch, cache invalidation/coalescing/tampering, private IO denial
and a failing unsandboxed control. The oracle provides independent expected
output; regenerated candidate JS is not its own golden.

## Shared compiler compatibility

The `NodeVarRef::isHashElement` correction makes valid hash-element `delete`
sources compile: it uses the actual receiver and inspects the last dereference
of the final variable level. Array-element and scalar deletion remain type
errors. This changes the shared Perl compiler, so production recompilation can
now accept valid deletion sources that previously failed. Existing stored
compiled layers retain their active bytes until recompiled.

The compact general fixture checks deletion in both the native Perl execution
and JavaScript execution. Separate array and scalar controls check rejection.
Recovery handles historical generated deletion independently; it does not
execute stored Perl.
