# Ordinary module placement

Historical qualification only: after the source-only cleanup, the retained
old server refuses selected journal user layers. Their settings are S2
source; the approved general server must compile that source and is not yet
wired to startup. No stored generated Perl reader remains in serving.

The private anonymous Recent/Entry viewer adds thirteen compiled user literals:
show/order/section for `userprofile`, `links`, `pagesummary`, `calendar`, and
`module_tags_section`. Existing tags show/order and the ten earlier literals
remain supported. Types are native bool/int/string; integers retain the absolute
10,000 resource bound. Both qualified layouts admit `none`, `one`, `two`:
Tabula uses main/secondary sections; EasyRead uses above/below entries.

The fully consumed native compiled wrapper is inert data, never executed.
Duplicate sets use their last value. Owner, parent, source, compiled bytes and
compile time remain bracketed and reread. Expressions, unknown properties,
wrong types, trailing bytes and unknown new section names refuse with fixed422.

Unchanged stock `modules_init` assigns in source order. A later module overwrites
an earlier module in the same slot, including credit/customtext/default modules.
Negative order is relative to the array length at assignment time; an index
before its beginning returns typed422 rather than silently truncating. The
existing engine section Proxy uses `Unsupported` only for this proven failure
and its explicit index resource bound; unrelated renderer errors remain errors. `none` is never
printed, but its assignments still execute and can fail on a negative empty
array. Frozen exact safe chunks are permissions to print, not mandatory output.

Profile/picture/website, links, public tags, selected visible page summaries and
calendar use existing approved public facts. Hiding a module never bypasses
privacy or final freshness checks. Calendar counts exclude private/usemask rows;
hidden comments/authors remain absent. Calendar links go to the retained app;
no local Day/Month/Year route is added. Calendar month0/neighbor quirks remain.

New placement properties select the already-qualified inline stylesheet path.
The existing hook identity guard and EasyRead omission inventory are unchanged;
there is no typography, array, label or general executable-layer support.
Historical pages without these properties retain their prior output.
